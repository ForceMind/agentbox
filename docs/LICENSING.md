# AgentBox Licensing Status

Status: **Requires Human Approval**

No final license has been accepted and no root `LICENSE` file is present.

ADR 0008 proposes Apache License 2.0 because it is permissive, widely accepted, and contains an express patent grant. MIT remains the simpler permissive alternative but has no equivalent express patent language. AGPL-3.0 would require corresponding source for modified network-service deployments but may reduce enterprise adoption and needs deeper compatibility/business review.

Until the maintainers formally accept a license and add its canonical text, repository publication does not itself grant a reusable open-source license beyond rights supplied by applicable law.

Before the first public release, human review must:

1. accept or replace ADR 0008;
2. verify direct and transitive dependency license compatibility;
3. add the canonical `LICENSE` text and any required `NOTICE`;
4. document copyright/header policy;
5. add an independent-project and third-party trademark notice.

Codex, Claude, GitHub, Linux distribution names, and other third-party marks are used only for factual compatibility descriptions. AgentBox does not claim affiliation or endorsement.
