## Scope

The internal production factory reads only the fixed Runtime-owned raw 32-byte
X25519 key file. It verifies exact non-root Runtime real/effective/saved identity,
passwd/group agreement, root-to-key directory entries, ownership/modes, single
link, bounded bytes and stable held descriptors. `take()` transfers ownership
once; access requires a single bind to the same verified manifest authority used
for executor creation. The derived public fingerprint must match before epoch
commit or stream construction.

Every read revalidates the path entries and key fingerprint. Close failures are
sticky and never retried by FD number. Construction cleanup attempts all held
FDs once and reports a bounded incomplete-cleanup error with sanitized original
failure. Python memory does not promise hardware zeroization. No key, public-key
bytes, private path or fingerprint fragments enter repr/errors/logs.

See [the C1 contract](../WAW_R12_RUNTIME_KEY_PORT.md). Production auth isolation,
the concrete executor provider and Runtime main wiring remain C2/C3 work.
Provider Secret, Browser Trust and Root Helper receive no new authority.
