# AgentBox 0.3.0rc14 — Recent Attention view

This source candidate adds one authenticated, read-only Attention page backed
by the existing bounded Jobs API. It shows only Jobs whose stored status is
`needs_attention`, links valid formal Project IDs, and hides the result while
the browser observation is stale. It does not infer task outcomes from terminal
text, disclose Job summaries, or perform recovery actions.

The API currently returns the 100 most recent Jobs. The page clearly labels
that limit; older attention Jobs are not a complete inbox in this version.
Existing WAW/R12 host, client, real CLI, and production qualification remain
separate and unverified by this change.

Version mapping: Python `0.3.0rc14`, npm `0.3.0-rc.14`, inert MV3 `0.3.0.14`.
No tag, GitHub Release, host activation, client installation, or real
credential operation follows from this source change.

## Local validation

- 49 focused Web tests across Attention, i18n, AppShell and workspace
  contracts passed; the two MV3 version tests and 60 release-candidate unit
  tests passed. Web typecheck and targeted ESLint passed.
- The isolated real-browser E2E completed 98 passed and 28 skips. The new
  Attention case ran in desktop Chromium (1280×800) and mobile Chromium
  (390×844); it checked authenticated routing, stored Job filtering, Project
  links, raw-summary exclusion, and absence of horizontal overflow.
- Root Web/MV3 build and documentation link check passed. The Vite chunk-size
  warning predates rc14: a same-host rc13 baseline built with Vite 7.3.6 was
  582.17 kB JS (166.49 kB gzip); rc14 was 587.01 kB (167.85 kB gzip).
  This is bundle size, not measured page latency.

Local browser and Python testing ran on macOS; the release-candidate unit
environment used Python 3.14. These results do not qualify the target Linux
host or supported Python 3.11–3.13 tuples. Exact-head CI and merge read-back
remain pending for this candidate.
