# AgentBox 0.3.0rc24 — navigation label catalog and Project assignments

The AgentBox Control Plane now owns a per-administrator navigation label
catalog and ordered assignments to formal Projects. A label has an immutable
ID, one of ten colors and a revisioned name; assignment sets use their own
revision so stale clients cannot silently overwrite one another. Rename and
recolor leave assignment identity intact, while deleting a label atomically
removes its assignments and reports the affected Project count. The
authenticated, no-store API requires Origin and CSRF for every mutation.

This is the backend/API foundation of
[WS14 Project and Workspace labels](../WORKBENCH_PROJECT_LABELS.md). The Web picker/manager, Workspace
assignments and cross-device/host synchronization are not delivered by this
candidate. No Runtime, file, Agent or Secret authority is granted by a label.

`0.3.0.24`.
