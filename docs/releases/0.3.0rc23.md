# AgentBox 0.3.0rc23 — command center navigation

The authenticated AgentBox shell now has a command center for fixed page and
formal Project navigation. Desktop and mobile users can open it from the
shell or with `Ctrl/Cmd+K`, search current Project metadata, select with
arrow keys and Enter, and close with Escape. The Project list is read again
for the active session when the dialog opens; a failed read does not hide
fixed page destinations. This adds no Runtime action, arbitrary command,
file content read, Secret access, or upstream service.

[Command center contract](../WORKBENCH_COMMAND_CENTER.md) records source
provenance, limits and remaining WS14 actions. Python, npm and inert MV3
versions map to `0.3.0rc23`, `0.3.0-rc.23` and `0.3.0.23`.
Local browser E2E completed 108 passes and 28 prescribed skips on desktop
and mobile Chromium; the command center used the local test server's real
formal Project list and screenshots were inspected. The Node 22 full Web
suite passed 1181 tests before the final abort test, whose focused set
passed 11/11. Web format/lint/typecheck/build, 87 Python release-candidate
tests, two inert MV3 version tests and 540 documentation links passed. The
final JS bundle is 617.49 kB/176.47 kB gzip; its >500 kB warning predates
this candidate. Exact-head CI and browser confirmation of the final
read-cancellation change are pending. Details are in
[CURRENT_STATE](../project/CURRENT_STATE.md). Real-host
and production qualification remain separate; this candidate creates no tag
or GitHub Release.
