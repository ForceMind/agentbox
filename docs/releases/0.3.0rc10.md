# AgentBox 0.3.0rc10 — Workspace return-state verification

Source candidate only. No tag, GitHub Release, deployment, real-host activation,
Provider Secret operation, or new platform qualification is implied.

## Scope

WEV-1 improves the existing browser Workspace workflow: lifecycle interruptions
invalidate Runtime observations and old Stop confirmations; returning to a
visible, online document requests fresh metadata before controls are available.
Return events do not start, resume, stop or reconnect an Agent automatically.
The displayed reception time is a browser snapshot timestamp, not server time
or a trust/health guarantee. The event contract introduces no arbitrary TTL.

The existing browser-first-language rule, typed localized error projection,
bounded terminal, exact ownership, and inert trust-provider boundaries remain.
No new API route, database table, third-party dependency, or Files/Task/Approval
surface is added. R12 still covers the unresolved production bootstrap,
Runtime provider, managed-browser trust installation and real CLI/host evidence.
