# AgentBox 0.3.0rc16 — Changed Paths page

This source candidate adds an authenticated Changed Paths page reachable from
a READY Project. It reads the rc15 Project Git Changes metadata API,
groups and orders paths with the migrated Changes tree, and exposes change
kind plus staged/unstaged state. Folder collapse, bounded load-more,
explicit refresh, stale-on-hide, empty, non-Git and failure states are
separate. File names are rendered as text with control and invisible format
characters escaped. The page never requests file content, patch hunks,
staging, commit or arbitrary host paths. Its visible copy states the
metadata-only scope; [A3](../WORKBENCH_A3_GIT_CHANGES.md) still requires a
separate sensitivity-aware patch contract.

Source version mapping: Python `0.3.0rc16`, npm `0.3.0-rc.16`, inert MV3
`0.3.0.16`. Local validation: full Web suite 1149 passed on Node 22.23.2
with file parallelism disabled, six MV3 tests, 97 Python release/Project/Git
tests, and 100 passed/28 prescribed skipped isolated desktop/mobile Chromium
cases. Desktop and mobile screenshots were inspected after spacing
corrections. The Web main JS bundle is 598.88 kB/171.22 kB gzip, up from rc15
587.01/167.85 kB; the >500 kB warning predates this release candidate.
Exact-head Linux CI is pending. Browser rendering and Linux CI remain distinct
from real host and production acceptance. No tag, GitHub Release, host
activation, client installation or Provider credential operation follows
from this source change.
