# AgentBox 0.3.0rc3 — WAW API relay development candidate

Planned release display/tag: `v0.3.0-rc.3`. This source increment does not create
the tag, publish a GitHub Release, activate a host or inherit the real-host
qualification recorded for the `0.3.0rc1` artifact.

## Included software

- Native RFC 6455 parsing/control with fixed path, Origin/subprotocol and resource
  budgets before ASGI application delivery.
- Real staged-admission coordination and opaque key/ciphertext relay to the
  Runtime inherited Unix stream; API holds no channel key or plaintext terminal.
- Current Session/scope/epoch/lease/health checks at actual publication, bounded
  ACK/control mapping and exact cleanup/Audit fences.
- One encoded INPUT ownership token across native ready, ASGI delivery, relay
  queue and Runtime send, with exact release or synchronous overflow fencing.
- Global 128-slot/8 MiB parser accounting including retained capacity, temporary
  copies and allocation growth reservations.

## Verification boundary

Local API/Runtime matrices and independent review are recorded in
[CURRENT_STATE](../project/CURRENT_STATE.md). Exact-head CI/merge evidence remains
pending. Tests use actual temporary TCP/Unix sockets and native WebSocket
handling, with explicitly synthetic PTY/key/peer/host inputs. They are software
evidence only. The full isolated Chromium suite passed 62 cases; desktop and
390x844 mobile visual read-back showed the `0.3.0rc3` version card without
horizontal overflow or overlap.

## Not included

- Independent browser trust provider, terminal model/controller and full browser
  interaction remain R9 work.
- Fixed interactive Claude/Codex processes and integrated fault qualification
  remain R10/R11 work.
- Linux pidfd/systemd/PTY/key custody, isolation, login, reboot and product
  qualification remain R12 gates.

The `0.3.0rc1` Quickstart applies only to that earlier qualified artifact. This
development candidate must not be installed from those commands without a newly
reviewed artifact and host qualification.
