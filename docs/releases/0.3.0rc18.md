# AgentBox 0.3.0rc18 — Project work tabs

This source candidate adds a bounded navigation strip for authenticated
Project detail, Changed Paths and Project/AgentType Workspace routes. Tabs are
scoped to the current administrator session, remain in memory only, deduplicate
by formal Project and view identity, and retain at most twelve entries. Closing
the active tab navigates to an adjacent tab or Projects; it never calls a
Runtime lifecycle action. Reopening a Workspace re-enters through its formal
Project/AgentType route so the existing controller revalidates the current WAW
row. Tab state grants no file, terminal, attach or Stop authority.

The pure ordering and active-fallback behavior adapts the fixed upstream
workspace pane model, with source and license recorded in
[work tab provenance](../WORKBENCH_PROJECT_TABS.md). This does not yet provide
multiple Agent conversations, cross-device tab sync, split panes, persisted
tabs or a second WAW record for the same Project/AgentType.
