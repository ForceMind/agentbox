# AgentBox 0.3.0rc25 — Project label management in Web

The authenticated Project page now reads the rc24 shared label catalog and
its own ordered assignment set. Administrators can create a fixed-color
label, assign or remove it, rename/recolor it, inspect the number of affected
Projects and confirm deletion. Each mutation waits for the server's exact
revision acknowledgment and fresh GET readback. Conflicts or uncertain
outcomes show bounded feedback and re-read state without automatically
replaying a write. Old-session results are hidden and pending requests are
aborted on Project/session/visibility changes.

Deletion includes the previewed affected-Project count in the API request.
The Control Plane compares it inside the deletion transaction, so a new
assignment made after preview cannot silently widen the deletion. Labels
remain navigation metadata and grant no Runtime, file, Agent or Secret
authority. The [label contract](../WORKBENCH_PROJECT_LABELS.md) records
remaining Workspace assignment and cross-host synchronization work.
