# AgentBox 0.3.0rc20 — Project search

The authenticated Projects page now filters its already-loaded formal
Projects by visible name, slug and printable branch. Terms may match across
fields and in any order; exact, prefix, word-boundary, substring and bounded
within-word subsequence matches rank deterministically. An empty query keeps
the API's original order. The page distinguishes no matching Projects from an
account with no Projects, shows a result count and clear action, and keeps
the query in page memory only. It sends no search text to API, Worker or
Runtime and grants no command/file capability.

The pure matching tiers adapt the fixed upstream text matcher; source digest,
license and scope are recorded in
[Project search provenance](../WORKBENCH_PROJECT_SEARCH.md). Favorites,
synced labels, global command center and unloaded Project pagination remain
separate WS14 work.
