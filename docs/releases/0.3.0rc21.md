# AgentBox 0.3.0rc21 — Project favorite metadata API

This source candidate adds a per-AdminUser/formal-Project preference table
with an additive Alembic migration. The transactional service treats an
absent row as `favorite=false, revision=0`, uses SQLite `BEGIN IMMEDIATE` and
revision CAS for insert/update, preserves same-value revisions, and writes
bounded Audit metadata in the same transaction. Downgrade refuses to drop a
nonempty favorite table. The authenticated no-store GET and CSRF/Origin
protected PUT routes return only typed favorite/version metadata. Neither
route invokes Runtime or accesses Project paths, file content or Secrets.

The [WS14 contract](../WORKBENCH_PROJECT_FAVORITES.md) retains the browser
toggle, conflict/uncertain-write recovery, favorites across sessions and
later labels/command center as separate work. This release candidate does
not claim a user-facing favorite control.
