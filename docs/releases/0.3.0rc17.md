# AgentBox 0.3.0rc17 — Git content-root foundation

This source candidate introduces internal `GitContentRoot` descriptor custody
for a future A3 Project Git patch reader. It opens and revalidates the fixed
Project directory, `.git`, objects/info/pack directories and index/config/HEAD
files. Directory and file identity, owner/group, unsafe writable permissions,
symlink replacement, commondir and alternate object stores fail closed. A
failed context entry closes every held descriptor.

The class does not export a descriptor, start Git, read file/patch bytes, add
a Runtime action or add an API route. It is only one prerequisite of the
[A3 patch content contract](../WORKBENCH_A3_PATCH_CONTENT_CONTRACT.md). Full
object-store provenance, child-cwd binding, selection IDs, encrypted content
transport, real-host qualification and visible diff remain unfinished.

Source version mapping: Python `0.3.0rc17`, npm `0.3.0-rc.17`, inert MV3
`0.3.0.17`. Local validation: 165 Git/content-root/release Python cases,
Linux-target mypy over 323 files, scoped Ruff/Black, Web/MV3
format/lint/typecheck/build and four targeted version tests passed. The
Web main bundle is 598.88 kB/171.21 kB gzip; its >500 kB warning predates
rc17. Isolated desktop/mobile Chromium E2E completed 100 passes and 28
prescribed skips, including the visible rc17 version. Exact-head Linux CI
is pending. Results are tracked in
[CURRENT_STATE](../project/CURRENT_STATE.md). No tag,
GitHub Release, host activation, client installation or Provider credential
operation follows from this source candidate.
