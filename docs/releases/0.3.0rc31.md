# AgentBox 0.3.0rc31 — bounded work overview

The Dashboard now leads with current-user Needs Attention and Active Work
windows, followed by recently updated Project metadata. Counts describe only
the 100 latest-created Jobs for the authenticated user. Recent projects are a
fixed six-record window of the existing shared administrator catalog, ordered
by actual metadata update time. Neither view infers AI progress or last use.

Both read paths use existing authenticated Control Plane models. The recent
Project endpoint does not reconcile the filesystem or fan out to Runtime/Git.
Stale snapshots are cleared across visibility, offline, page lifecycle and
session changes. Loading, empty, error and permission feedback remain distinct;
existing health/readiness and administration links are preserved.

The [bounded contract](../WORKBENCH_WORK_OVERVIEW.md) records permissions,
truthful window semantics, timestamps, lifecycle and the acceptance matrix.
Python/npm/inert MV3 source versions are `0.3.0rc31`, `0.3.0-rc.31`, and
`0.3.0.31`. Older release-gate results retain their historical semantics.

This is a software candidate. Exact-head CI, actual formal App desktop/phone
rendering and independent pixel review must pass before merge. It is not a tag,
Release, deployment, production key/pin enrollment or real host/CLI acceptance.
