# AgentBox 0.3.0rc29 — Workspace labels in the command center

On an authenticated `/workspace/aws_…` route, the command center reads the
exact formal Workspace metadata, the current administrator's shared label
catalog and that Workspace's assignment set. Query-only label choices show
whether each label is assigned. Selecting one toggles precisely that label
through the existing Origin/CSRF protected Workspace CAS API, waits for an
exact revision ACK and fresh GET readback, then refreshes the visible label
panel. Conflicts and uncertain delivery re-read without automatically
replaying the write. The modal cannot navigate or close during a pending
write. A malformed or unavailable Workspace never becomes a label action;
fixed page/Project navigation remains available.

AgentBox uses its own Web/API/Project/Workspace identities and adds no
arbitrary command, file, Runtime, plugin or Secret authority. A bare
`/workspace` route without an exact Workspace ID keeps the separate label
panel and does not offer command-center label mutations. Cross-host sync
and broader upstream command contributions remain later work.
