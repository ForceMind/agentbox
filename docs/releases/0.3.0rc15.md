# AgentBox 0.3.0rc15 — Project Git Changes metadata

This source candidate adds `GET /api/v1/projects/{project_id}/git/changes`
for an authenticated administrator and READY Project. It returns bounded
relative path/status metadata from the Runtime's fixed Git action. A
snapshot-bound cursor pages through the result and rejects drift; it does
not return file text, patch bodies, Git arguments, terminal output or
Provider Secrets. The [A3 contract](../WORKBENCH_A3_GIT_CHANGES.md) lists
limits, errors and remaining user-visible work.

Python `0.3.0rc15`, npm `0.3.0-rc.15`, and inert MV3 `0.3.0.15` are
consistent across all source entry points. Local Git/Project API/release
checks completed 164 passes; Web/MV3 version tests and builds passed. The
isolated browser E2E completed 98 passes and 28 prescribed skips across
desktop and mobile Chromium. These browser checks cover version visibility
and existing flows, not a Changes UI. Linux exact-head CI remains required.
No tag, GitHub Release, host activation, browser installation or real
credential operation follows from this source change. R12 qualification
and the full 70-capability integration goal remain separate and unfinished.
