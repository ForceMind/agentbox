# AgentBox 0.3.0rc19 — descriptor-bound child cwd

This source candidate adds an internal Linux-only `ControlledProcessRunner`
entry point for a future fixed Git content action. It duplicates a caller-held
Project directory descriptor, verifies that it matches the named Project,
uses `/proc/self/fd/<fd>` as the child cwd with only that descriptor passed to
the child, and rechecks the named identity before returning bounded output.
Cancellation, timeout, stdout/stderr caps, sanitized environment, exact
process-group cleanup and executable identity remain shared with the existing
runner. A non-Linux host fails closed. There is no new Runtime action, API
route, browser control, file read or patch result.

The rc17 `GitContentRoot` and this cwd seam are separate internal foundations.
They have not been composed into a content reader. Object-file provenance,
staged-only extraction, selector and encrypted content transport remain
required by the [A3 patch contract](../WORKBENCH_A3_PATCH_CONTENT_CONTRACT.md).
The [cwd proof record](../WORKBENCH_A3_GIT_CWD.md) specifies its limits.
