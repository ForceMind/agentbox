# AgentBox 0.3.0rc2 — WAW Runtime development candidate

Planned release display/tag: `v0.3.0-rc.2`. This development increment does
not create the tag, publish a GitHub Release, activate a host or inherit the
real-host qualification recorded for `0.3.0rc1`.

## Included software

- Runtime-owned Noise/AWCE attachment sessions over the fixed WAW wire profile.
- A bounded inherited Unix stream listener with authenticated peer/capability,
  exact tuple/epoch/lease and ready/commit fences.
- Encrypted input results, output ring/cursor/GAP handling, detach/reconnect and
  exact cleanup evidence without API plaintext or keys.
- Socket publication invalidation for detach, expiry and exact Stop, including
  partial writes, late workers and old-generation isolation.
- Correct 2,000 logical-line retention and a deadlock-free
  `supervisor → executor map` Start replacement transaction.

## Verification boundary

Local Runtime regression, static checks, independent review, browser version
display and exact-head CI evidence are recorded in
[CURRENT_STATE](../project/CURRENT_STATE.md) and the R7 pull request. The release
workflow builds an unsigned candidate for review; it does not confer publisher
authenticity or production support.

## Not included

- The R8 API ciphertext relay is still under review for its shared INPUT budget.
- Browser trust-provider lifecycle, terminal model/controller and visible
  interaction remain R9 work.
- Fixed interactive Claude/Codex process composition and software integration
  remain R10/R11 work.
- Real Linux peer/pidfd/systemd/PTY/key custody, isolation, login, reboot and
  product qualification remain R12 gates.

Use the `0.3.0rc1` Quickstart only for that earlier qualified artifact. Do not
apply those installation instructions to this development candidate without a
new reviewed artifact and host qualification.
