# AgentBox 0.3.0rc9 — R11 bilingual UI candidate

Planned release display/tag: `v0.3.0-rc.9`. This is a local software candidate,
not a delivered or merged release. It creates no tag or GitHub Release, activates
no host capability, handles no credential, and does not inherit R12 qualification.

## Candidate scope

- Full route/state migration to typed English and `zh-CN` catalogs, with catalog
  key parity enforced by TypeScript and tests.
- A document chooses its immutable locale from only `navigator.languages[0]`:
  primary `zh` selects `zh-CN`; every other, absent or malformed first preference
  selects English. Later preferences and `navigator.language` have no effect
  until a new document/reload.
- UI API-error handling maps stable error codes to the selected catalog. It does
  not render API/server prose as a localization fallback.
- Technical values remain English: identifiers, protocol fields, enum values,
  database names, error codes, Audit actions, source names, filenames, branches,
  commits and versions. User and Project names remain user-provided Unicode data.
- E2E uses a distinct-origin, test-only Workspace harness. The production bundle
  contains no test bypass. Sensitive terminal scenarios use non-sensitive data
  and disable trace, video and screenshots.

## Version and release-gate contract

- Python: `0.3.0rc9`; npm: `0.3.0-rc.9`; MV3: `0.3.0.9`.
