# AgentBox 0.3.0rc6 — R11 browser-controller composition candidate

Planned release display/tag: `v0.3.0-rc.6`. This source increment does not
create a tag, publish a GitHub Release, install a systemd unit/socket, activate
a host, install a Chromium extension, handle a credential, or inherit real-host
qualification from any earlier candidate.

## Included software

- One browser attachment/page owner over the typed controller, bounded DOM
  renderer, managed Chromium provider availability and exact page lifecycle
  fences.
- A fixed 8px × 20px terminal viewport calculation, bounded input ownership,
  IME handling, fresh redraw/reconnect, and exact `Detach -> Stop` composition.
- Project/binding currentness at WebSocket admission and active relay
  publication, plus durable generation-bound Stop compensation after a
  post-Start Project/binding drift.
- Browser-selected `zh-CN` or English Workspace status and terminal controls;
  technical identifiers and protocol values stay English.
- One version source: Python uses `0.3.0rc6`; root, Web and browser-extension
  packages use `0.3.0-rc.6`; the MV3 inert manifest maps it to `0.3.0.6`.

## Verification boundary

The source checkpoint passed 983 Web tests, 117 API/relay tests and 64 E2E tests
locally, along with type, format, lint, build, mypy and independent review.
Exact-head CI, normal merge and read-back are recorded separately. These checks
do not establish a signed CRX/trustd deployment, real provider enrollment,
vendor CLI login, PTY/isolation, systemd/reboot evidence or product support.

## Not included

- R11 rc7 deterministic failure injection, rc8 artifact/upgrade/rollback
  rehearsal, or rc9 full route/state localization.
- R12 host activation and qualification, including real key custody, Chromium
  policy, Native Messaging/trustd install, CLI/PTY behavior and reboot recovery.
