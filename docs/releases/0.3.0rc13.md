# AgentBox 0.3.0rc13 — Native auth-probe substrate

R12-C2 native software candidate. This is not full C2, C3, Runtime main
availability, or product qualification. No real key, CLI login, client install,
host activation or production operation occurred.

## Scope

The Runtime native layer now has a closed `--auth-probe` mode separate from the
interactive WAW ABI. It accepts one exact 160-byte network-order `AWP1` record
on a `SOCK_SEQPACKET` control peer, verifies `SO_PEERCRED` against the sealed
parent identity, requires a sender half-close after the single record, and emits
an independent 8-byte `AWRP` placed record only after cgroup placement and
current-generation validation.

The helper validates fixed FD roles 0–8, per-generation scratch identity, vendor
HOME and policy ownership, and held vendor executable type. Auth execution uses
fixed Claude/Codex status argv and eleven-key environments, private mount/user/
PID/IPC/network namespaces, auth-only Landlock/seccomp, no Project/PTY/bridge/
tmux authority, parent-death protection, pidfd/wait cleanup, and bounded output
ownership. The existing interactive bridge, WBR records and seven-role launch
ABI remain unchanged.

The Runtime/lease owner remains responsible for removing host scratch residue
after native cleanup proof; native does not delete the borrowed generation cgroup
or host source directory. Python auth lease/cache/provider wiring, five-second
operation ownership, Runtime main composition and real vendor qualification are
not included in this candidate.

## Verification

The native source has portable build/gate checks on macOS. Linux auth behavior
requires the dedicated GitHub host gate: cgroup v2, sibling parent/target groups,
user/PID/mount/IPC/network namespaces, Landlock, seccomp, pidfd and AppArmor
settings. The backend workflow creates root-owned auth mount anchors, Runtime-owned
per-generation scratch, root-owned policy directories, and a target sibling cgroup;
the normal and sanitizer native commands include the new auth tests.

Current local evidence is portable only: the Linux auth test module is skipped on
macOS. A successful portable check is not Linux host evidence. Exact-head CI must
run normal and sanitizer native auth tests before this candidate can be merged.
The unified mapping is Python `0.3.0rc13`, npm `0.3.0-rc.13`, and MV3
`0.3.0.13`.
