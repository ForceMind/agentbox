# AgentBox 0.3.0rc22 — Project favorites UI

The authenticated Projects page now reads the rc21 per-admin favorite API
and offers an accessible favorite button beside each formal Project link.
The button does not optimistically claim success: it waits for the server's
exact Project ID, desired boolean and next revision. A conflict or uncertain
acknowledgment triggers a fresh GET without replaying the PUT; the page shows
bounded localized feedback, disables stale controls, and revalidates on
browser return or session change. Saved favorites sort first when search is
empty; ranked search order is preserved while a query is active. No terminal,
file, Runtime or Provider authority is added.

The rc21 API revision is capped to JavaScript's exact integer range before
Web use. [WS14 favorites](../WORKBENCH_PROJECT_FAVORITES.md) records the
remaining label, order-customization and command-center work. Source version
